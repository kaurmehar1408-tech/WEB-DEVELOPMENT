Content container tags

SMALL TAG: It is used to set the small font-size of the text document.
BIG TAG: It is used to set the big font-size of the text document.
SUPERSCRIPT TAG: Displays the text as superscript
SUBSCRIPT TAG: Displays the text as subscript
INS TAG: It is used to underline a text marking the text as inserted or added.
DEL TAG: It is used to represent the deleted text.By a crossed or strike out the text content with a horizontal line.
MARK TAG: makes the text highlight
ABBR TAG: used to abbreviate a text. The title attribute is used to define the full form of the abbreviated text.
